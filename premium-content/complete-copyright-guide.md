# SECTION 1: COPYRIGHT BASICS

## 1.1 What Copyright Protects

Copyright protects original works of authorship fixed in a tangible medium:

| Category | Examples | Common Issues |
|----------|----------|---------------|
| Literary works | Books, blog posts, manuals | Website text, app copy |
| Musical works | Songs, compositions | Background music in videos |
| Dramatic works | Plays, scripts | Course scripts |
| Pictorial/graphic | Photos, illustrations | Product images |
| Motion pictures | Videos, films | Course videos |
| Sound recordings | Audio recordings | Podcast episodes |
| Architectural | Building designs | Rarely relevant |
| Software | Code, apps | Course platforms |

## 1.2 What Copyright Does NOT Protect

❌ Ideas, facts, and discoveries
❌ Titles, names, and short phrases
❌ Common property information
❌ Government works (mostly)
❌ Works not fixed in tangible form
❌ Processes and methods
❌ Systems and operations

## 1.3 The Registration Imperative

| Protection Aspect | Without Registration | With Registration |
|-------------------|---------------------|------------------|
| Protection begins | Upon creation | Upon creation |
| Federal lawsuit rights | NO | YES |
| Statutory damages | NO | YES ($750-$150,000) |
| Attorney fees | NO | YES (recoverable) |
| Legal leverage | Minimal | Maximum |
| Public record | NO | YES |

# SECTION 3: ONLINE COURSE REGISTRATION STRATEGY

## 3.1 Recommended Registration Approach

For a 42-video online course with workbooks:

| Component | Registration Type | Fee | Strategy |
|-----------|-------------------|-----|----------|
| All videos | Group registration | $65 | Single group application |
| Workbook (single PDF) | Single registration | $65 | One complete workbook |
| Template bundle | Single/Compilation | $65 | If separate, one registration |
| Scripts | Single registration | $65 | Literary work |

**Total: 4 registrations = $260**

## 3.2 Video Group Registration Requirements

**To qualify for video group registration, you need:**

1. **All videos must be:**
   - Same author(s) (or work made for hire)
   - Same basic nature (not a random collection)
   - Collected at the same time
   - Published within 3 months of each other OR unpublished

2. **You need:**
   - Complete application for the group
   - One complete video as deposit
   - Metadata for all videos (titles, publication dates)
   - Fee ($65)

## 3.3 Preparation Checklist

### For Video Group Registration:
- [ ] List all video titles exactly as they appear
- [ ] Note duration of each video
- [ ] Document creation dates
- [ ] Document publication dates (if published)
- [ ] Select representative video (best quality, shows full content)
- [ ] Export representative video at highest quality
- [ ] Verify file size (max varies by platform)

### For Written Work Registration:
- [ ] Finalize all content (no drafts)
- [ ] Add copyright notice to document: © [Year] [Author Name]
- [ ] Convert to PDF format
- [ ] Check file size requirements
- [ ] Ensure all pages are included

# SECTION 4: STEP-BY-STEP REGISTRATION PROCESS

## 4.1 Starting Your Application

**Step 1:** Go to https://copyright.gov/registration/

**Step 2:** Click "Log in to the eCO Portal"

**Step 3:** Create account OR log in with existing credentials

**Step 4:** Click "Start a New Registration"

**Step 5:** Select the type of work:

| If Your Work Is | Select |
|-----------------|--------|
| Literary work (books, manuals) | Literary Work |
| Course with videos | Performing Arts or Literary (depending on emphasis) |
| Photography | Visual Arts |
| Software/app | Computer Program |
| Sound recording | Sound Recording |

## 4.2 Completing the Application

### For Literary Work (Workbook/Course Materials):

**Title Tab:**
- Title of work: [Exact title]
- Title type: [Variant title/Previous title if applicable]
- Disclaimer: [N/A unless needed]

**Author(s) Tab:**
- Author name: [Full legal name - no pseudonyms]
- Author type: [Individual/Work made for hire]
- Contribution: [Author of entire work]
- Citizenship: [Select]
- Domicile: [Where you live]

**Claimant Tab:**
- How claimant obtained ownership: [Transfer/Assignment if different from author]
- Usually: Same as author

**Work Tab:**
- Work type: [Select from options]
- Publication/creation status: [Published/Unpublished]
- If published: Date and Nation of first publication
- If unpublished: Date of creation

**Rights & Permissions:**
- Fill in contact for licensing inquiries
- This appears publicly in the record

**Certification:**
- Check attestation box
- Type your name as signature
- Date

### For Video Group Registration:

**Title Tab:**
- Title: [Course name - "Course Name (Videos)"]
- Title type: Collective work or Group registration

**Author(s) Tab:**
- Author: [Your name or company name]
- Author type: Individual or Corporation (for work made for hire)
- Nature of authorship: [Motion picture/Authorship in motion picture]

**Claimant Tab:**
- Usually same as author
- Or company that owns the work

**Work Tab:**
- Work type: [Performing Arts]
- Special handling: [Usually No unless urgent]

**Group Registration Tab:**
- Number of videos: [Total count]
- For each video:
  - Title
  - Creation date OR publication date
  - Duration
  - Description (optional but helpful)

**Deposit:**
- Upload one representative video file
- Ensure it shows the full content
- Check file size limits

## 4.3 Uploading Your Deposit

| Work Type | What to Upload | Format | Size Limit |
|-----------|---------------|--------|------------|
| Literary | Complete manuscript (PDF) | PDF | 100 MB |
| Video | One video (representative) | MP4, MOV, AVI, WMV | 2 GB |
| Sound Recording | Complete recording | MP3, WAV, FLAC | 2 GB |
| Photograph | High-res image(s) | JPG, PNG, TIFF | 50 MB |
| Software | Complete source code | ZIP | 500 MB |

## 4.4 Paying the Fee

**Standard Processing:**
- $65 per registration
- Credit card accepted
- Confirmation email immediate

**Special Handling (Optional):**
- $800 additional fee
- 5-7 business day processing
- For urgent needs only

## 6.3 Copyright Infringement Lawsuit Basics

**Federal Court Requirements:**
- Must have valid registration (or pending application)
- Infringement must occur after registration OR after publication
- For maximum damages: Register BEFORE infringement occurs

**Available Remedies:**
| Remedy | Amount | When Available |
|--------|--------|----------------|
| Actual damages | Proven amount | Always |
| Infringer's profits | Discovered amount | Always |
| Statutory damages | $750-$150,000/work | Only with registration |
| Attorney fees | Court's discretion | Only with registration |
| Injunctive relief | Court order | Any infringement |

# QUICK REFERENCE: COMMON SCENARIOS

## Scenario 1: Online Course Creator
**Problem:** Selling digital course, worried about piracy

**Solution:**
1. Register videos as group ($65)
2. Register workbook ($65)
3. Register templates ($65)
4. Set up Google Alerts for unique content
5. Use DMCA service ($10/month monitoring)

## Scenario 2: Author
**Problem:** Published book on Amazon, found someone selling copies

**Solution:**
1. Register book with Copyright Office ($65)
2. Send DMCA takedown to Amazon
3. If no response: Formal cease and desist
4. If continues: Federal lawsuit for statutory damages

## Scenario 3: Photographer
**Problem:** Images stolen and used without permission

**Solution:**
1. Register image(s) ($65 for up to 750 images online OR $65 for single)
2. Send DMCA takedown to hosting platform
3. Demand compensation for past unauthorized use
4. Sue for statutory damages ($750-$30,000, up to $150,000 for willful)

## Scenario 4: Podcast Producer
**Problem:** Episodes being downloaded and reposted

**Solution:**
1. Register sound recordings ($65)
2. Register scripts/materials as literary work ($65)
3. Send cease and desist to infringers
4. Report to platforms (Apple, Spotify)
