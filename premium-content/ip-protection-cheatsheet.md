# TRADEMARK CHEATSHEET

## Search Before You File
```
URL: tess2.uspto.gov
Search: WORD marks (not designs)
Check: Same class + similar classes
Also: State databases, social media, domains
```

## Nice Classification Quick Guide
```
Class 9  → Apps, software, electronics
Class 35 → Business services, consulting
Class 41 → Education, training, courses
Class 42 → Tech services, SaaS
Class 45 → Legal, security services
Class 14 → Jewelry, watches
Class 25 → Clothing, apparel
```

## Filing Options
```
TEAS Plus: $250/class
TEAS Standard: $350/class
Recommendation: TEAS Plus (more requirements, but cheaper)
```

## Timeline
```
Filing to Approval: 8-12 months
Response Window: 6 months (don't miss!)
Section 8 (years 5-6): Maintain registration
Renewal: Every 10 years
```

## Specimen Types (Pick ONE+)
```
✓ Product labels / hang tags
✓ Packaging with your brand visible
✓ Website screenshot showing brand in commerce
✓ Point-of-sale displays
✓ Advertising showing use with products
```

# LLC FORMATION CHEATSHEET

## State Decision Matrix
```
Delaware → Investors, VC, serious growth plans
Your State → Local business, simplicity
Wyoming → Privacy, crypto, specific needs
```

## Filing Costs (Typical)
```
Delaware LLC: $90 + $199 registered agent
California: $70 + $70 registered agent
Texas: $300 (no additional agent fee)
New York: $200 + $100 registered agent
```

## Formation Checklist
```
□ Choose name (search state DB)
□ Check domain/social media availability
□ Select registered agent
□ File Articles of Organization
□ Create Operating Agreement
□ Get EIN (free: IRS.gov/ein)
□ Open business bank account
□ Set annual compliance reminders
```

## EIN Application
```
URL: IRS.gov/ein
Time: 15 minutes online
Cost: FREE
Format: "Apply online, receive immediately"
```

# COPYRIGHT CHEATSHEET

## What to Register
```
✓ Online courses (videos + materials)
✓ Workbooks and guides
✓ Templates and worksheets
✓ Photography
✓ Music and audio
✓ Software and apps
```

## Registration Costs
```
Single work: $65
Group (videos): $65 for group
Group (photos): $65 for up to 750
Compilation: $65 for collection
```

## Group Registration Rules
```
Videos: All same author, same nature, collected together
Photos: Up to 750 in single application
Not allowed: Mixed authors, different work types
```

## DMCA Takedown Timeline
```
Report to platform: 24-48 hours response
If no response: Formal notice with registration #
Still no response: Lawsuit in federal court
```

# CORPORATION CHEATSHEET

## When to Choose C-Corp
```
✓ Seeking VC or angel investment
✓ Planning to IPO
✓ Acquiring or being acquired
✓ Multiple co-founders with equity
```

## Delaware C-Corp Formation
```
Fee: $89 (+ $199 registered agent)
Shares: Authorize 10M common, $0.0001 par
Options: Reserve 10-20% for employee pool
```

## Must-Have Documents
```
□ Certificate of Incorporation
□ Bylaws
□ Founder stock purchase agreements
□ IP assignment agreements
□ Board resolutions
□ 83(b) elections (file within 30 days!)
```

## Compliance Calendar
```
Delaware Annual Report: March 1
California Foreign Qual: Annual
Board Meetings: Quarterly minimum
Shareholder Meetings: Annual
Federal Taxes: April 15 + extensions
```
